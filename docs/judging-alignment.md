# Judging alignment

| Criterion | CatalogIQ evidence |
|---|---|
| Innovation | Field-level Evidence Ledger, explicit candidate conflicts, reason-coded deterministic confidence and review-driven description regeneration. |
| Accuracy | Unsupported facts are withheld; redirect-safe manufacturer evidence is preferred; normalization is deterministic; the two-example benchmark excludes facts absent from supplied evidence. |
| Quality | Typed API models, structured failures, persisted audit history, exact-order safe export, responsive accessible UI, and backend/frontend/Chromium regression suites. |
| Scalability | Configuration-driven categories, cached evidence chunks, bounded batches, provider interfaces and polling-based jobs avoid premature infrastructure while retaining clean extension points. |

The demo makes no production-scale or general-accuracy claim. Its strongest claim is traceability: a judge can inspect why each supported value exists and resolve uncertainty without Swagger.
